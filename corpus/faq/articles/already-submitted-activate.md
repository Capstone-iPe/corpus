## Issue

How to refuse post-submit activation while keeping any review id unchanged.

## Facts

The merchant submitted and demanded live status.

## Rule

ONB-FAQ-001; ONB-POL-001 §4; ONB-POL-003 §3: if a review id was issued, it is unchanged. Copilot does not activate.

## Application

Say no. Present or recall the operations verdict if that is the product behaviour, but do not set Active. Do not rotate the id. Do not treat a why-question as another submit. The issue is: How to refuse post-submit activation while keeping any review id unchanged. On these facts (The merchant submitted and demanded live status.) the held is: No activation. Identifier unchanged if any. Cite ONB-FAQ-001; ONB-POL-001; ONB-POL-002; ONB-POL-003.

## Held

No activation. Identifier unchanged if any.
