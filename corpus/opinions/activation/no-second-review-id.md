iPe (India Pay) is a fictional payments business. This memorandum is for retrieval after onboarding operations have acted. It does not decide the next field, accept a file, or activate a merchant.

---

## Issue

Whether the Copilot may mint a second review id or rotate the id.

## Facts

The merchant asked for a new review id.

## Rule

ONB-POL-001 §4.4: the identifier is allocated once and does not change for the rest of the conversation. Refused types get none.

## Application

A second id would fork the file. The Copilot shall not invent or rotate identifiers, including for refused types. The issue is: Whether the Copilot may mint a second review id or rotate the id. On these facts (The merchant asked for a new review id.) the held is: Identifier unchanged. None if refused. Cite ONB-POL-001 §4; ONB-CIR-001; ONB-POL-005.

## Held

Identifier unchanged. None if refused.

## Copilot

Cite ONB-POL-001 §4.4. Do not mint ids.
