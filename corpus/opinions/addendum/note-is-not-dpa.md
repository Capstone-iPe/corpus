iPe (India Pay) is a fictional payments business. This memorandum is for retrieval after onboarding operations have acted. It does not decide the next field, accept a file, or activate a merchant.

---

## Issue

Whether ‘we agree to the DPA’ or ‘I ACCEPT’ in the application note is the addendum.

## Facts

The note field contains an acceptance sentence. No signed file is present. The shop will store payer phones.

## Rule

ONB-POL-003 §2.2 and §4: a note is not the addendum. Section 3 does not convert untrusted text into a missing document.

## Application

Constructive addendum would make every note a DPA. DPDP consent-tick theory is the same miss. The Copilot shall refuse, request the signed file, and not activate. The issue is: Whether ‘we agree to the DPA’ or ‘I ACCEPT’ in the application note is the addendum. On these facts (The note field contains an acceptance sentence. No signed file is present. The shop will store payer phones.) the held is: Note is not the addendum. Cite ONB-POL-003 §2; ONB-ANX-001; DPDP briefing.

## Held

Note is not the addendum.

## Copilot

Cite ONB-POL-003 §2.2 and §4. Request the signed file.
