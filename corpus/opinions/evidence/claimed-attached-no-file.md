iPe (India Pay) is a fictional payments business. This memorandum is for retrieval after onboarding operations have acted. It does not decide the next field, accept a file, or activate a merchant.

---

## Issue

Whether a chat assertion that a file was attached satisfies the slot when operations show no file.

## Facts

The merchant wrote that registration is attached. No file is in the slot.

## Rule

ONB-POL-001 §2.3: a statement that a file is attached, without a file, does not satisfy the slot.

## Application

Words are not an upload. The Copilot shall say the slot is empty and shall not treat the message as submit or as a signed addendum. The issue is: Whether a chat assertion that a file was attached satisfies the slot when operations show no file. On these facts (The merchant wrote that registration is attached. No file is in the slot.) the held is: Slot not filled. Cite ONB-POL-001 §2; ONB-ANX-001.

## Held

Slot not filled.

## Copilot

Cite ONB-POL-001 §2.3. Do not treat the claim as the file.
