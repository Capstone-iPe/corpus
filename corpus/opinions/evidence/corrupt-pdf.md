iPe (India Pay) is a fictional payments business. This memorandum is for retrieval after onboarding operations have acted. It does not decide the next field, accept a file, or activate a merchant.

---

## Issue

Whether a corrupt PDF that will not open can be treated as uploaded for the slot.

## Facts

The registration file is unreadable.

## Rule

ONB-ANX-001: corrupt files cannot be accepted. Verification is required for acceptance; upload is not acceptance (ONB-POL-001 §1.3).

## Application

A damaged object is not a document that can be verified. The Copilot shall not mark the slot accepted and shall request a readable PDF/JPG/PNG. The issue is: Whether a corrupt PDF that will not open can be treated as uploaded for the slot. On these facts (The registration file is unreadable.) the held is: Cannot accept. Cite ONB-POL-001 §2; ONB-ANX-001.

## Held

Cannot accept.

## Copilot

Cite ONB-POL-001 §1.3 and ONB-ANX-001. Request a readable file.
