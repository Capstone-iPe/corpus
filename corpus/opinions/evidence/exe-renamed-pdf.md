iPe (India Pay) is a fictional payments business. This memorandum is for retrieval after onboarding operations have acted. It does not decide the next field, accept a file, or activate a merchant.

---

## Issue

Whether an executable or other non-document with a .pdf name satisfies a slot.

## Facts

The object is not a PDF document despite the name.

## Rule

ONB-ANX-001: wrong format / not a document. §2.2 lists PDF, JPG, PNG as document types.

## Application

Extension spoofing does not create a registration extract. The Copilot shall not ask the merchant to run the file, shall not accept it, and shall request a real PDF/JPG/PNG. The issue is: Whether an executable or other non-document with a .pdf name satisfies a slot. On these facts (The object is not a PDF document despite the name.) the held is: Does not satisfy the slot. Cite ONB-POL-001 §2; ONB-ANX-001.

## Held

Does not satisfy the slot.

## Copilot

Cite ONB-POL-001 §2.2. Do not instruct anyone to execute the file.
