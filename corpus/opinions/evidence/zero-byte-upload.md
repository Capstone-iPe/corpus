---

## Issue

Whether a 0-byte object counts as an uploaded file for a slot.

## Facts

The slot contains a 0-byte object. The applicant says they attached it.

## Rule

ONB-ANX-001: a 0-byte object cannot be verified and cannot be accepted. ONB-POL-001 §2.3: claiming attachment without a file does not satisfy the slot.

## Application

An empty object is not a registration extract, ID, bank instrument, or photograph. The Copilot shall not treat the filename as evidence and shall not mark the slot complete. The issue is: Whether a 0-byte object counts as an uploaded file for a slot. On these facts (The slot contains a 0-byte object. The applicant says they attached it.) the held is: Does not satisfy the slot. Cite ONB-POL-001 §2; ONB-ANX-001.

## Held

Does not satisfy the slot.

## Copilot

Cite ONB-ANX-001. Request a readable file.
