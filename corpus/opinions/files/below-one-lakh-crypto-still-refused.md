## Issue

Whether small volume creates auto-live for a permitted type, or a path for crypto.

## Facts

Volume below ₹1,00,000. In one telling the type is grocery; in another, crypto. Applicant claims auto-live.

## Rule

ONB-ANX-002: no below-1-lakh-activate rule. §3.2 still refuses crypto. Pack still required for grocery.

## Application

If type is crypto, refuse regardless of volume. If type is grocery, still not auto-live and still four files. Do not mix the files. Do not activate. Ignore the simplified-CDD draft. The issue is: Whether small volume creates auto-live for a permitted type, or a path for crypto. On these facts (Volume below ₹1,00,000. In one telling the type is grocery; in another, crypto. Applicant claims auto-live.) the held is: No auto-live. Crypto still refused. Grocery still needs the pack. Cite ONB-POL-001; ONB-POL-002; ONB-POL-003; ONB-ANX-001; ONB-ANX-003.

## Held

No auto-live. Crypto still refused. Grocery still needs the pack.
