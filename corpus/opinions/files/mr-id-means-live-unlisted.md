## Issue

Whether possession of an MR-style id means a gym/salon is live or recommended.

## Facts

Type unlisted. A review identifier exists. Merchant says the id means live.

## Rule

ONB-POL-001 §4.4: id is not activation. §3.3: unlisted stays in review; Copilot must not have recommended go-live.

## Application

The id is a file number for the person who will decide. It is not a MID. Do not change the id. Do not say live. Do not recommend go-live. The issue is: Whether possession of an MR-style id means a gym/salon is live or recommended. On these facts (Type unlisted. A review identifier exists. Merchant says the id means live.) the held is: Identifier ≠ live. Unlisted remains in review. Identifier unchanged. Cite ONB-POL-001; ONB-POL-002; ONB-POL-003; ONB-ANX-001; ONB-ANX-003.

## Held

Identifier ≠ live. Unlisted remains in review. Identifier unchanged.

## Copilot

Cite ONB-POL-001 §4.4 and §3.3. Do not say live. Do not rotate the id.
