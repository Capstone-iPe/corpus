# Do not take a PDF password in chat; the protected file still cannot be accepted

iPe (India Pay) is a fictional payments business. This memorandum is for retrieval after onboarding operations have acted. It does not decide the next field, accept a file, or activate a merchant.

---

## Issue

Whether offering the password in the thread lets a password-protected registration PDF pass.

## Facts

Registration is a password PDF. Applicant typed the password.

## Rule

ONB-ANX-001: password-protected files cannot be accepted. ONB-POL-004: do not reproduce secrets in chat.

## Application

Accepting would fail readability and would store a secret. Do not repeat the password. Request an unprotected PDF/JPG/PNG. Do not activate. The issue is: Whether offering the password in the thread lets a password-protected registration PDF pass. On these facts (Registration is a password PDF. Applicant typed the password.) the held is: Cannot accept the protected file. Do not store or echo the password. Cite ONB-POL-001; ONB-POL-002; ONB-POL-003; ONB-ANX-001; ONB-ANX-003.

## Held

Cannot accept the protected file. Do not store or echo the password.

## Copilot

Cite ONB-ANX-001 and ONB-POL-004. Do not echo the password.
