Terms

Retrieval modes in one line each

Dense

Embed the query; rank chunks by vector similarity (cosine). Captures paraphrase.

Keyword

Match query tokens against an inverted index. Captures exact ids and rare phrases.

Hybrid

Run both, fuse with RRF (+ folder bonus). What the live API uses.

Hybrid + MiniLM rerank

Re-score the hybrid pool with a cross-encoder. Local probe only — hurt hit@4 here; needs torch.

Metrics: hit@k = fraction of questions with ≥1 gold doc in top‑k. mean recall@k = average fraction of each question’s gold set recovered in top‑k. Deeper definitions and build internals → team notes.
