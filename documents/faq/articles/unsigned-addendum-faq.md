## Issue

How to explain that ticks, notes, ISO, and unsigned PDFs are not the DPA.

## Facts

The merchant offered a tick, note, ISO, or unsigned template instead of a signed addendum, and will store payer phones.

## Rule

ONB-POL-003 §2.2–2.4.

## Application

Say iPe needs a signed addendum file if they will store customer phones. A website tick, ISO certificate, or blank signature block is not that file. If they will not store phones, do not demand it. Do not print phones. Do not activate. The issue is: How to explain that ticks, notes, ISO, and unsigned PDFs are not the DPA. On these facts (The merchant offered a tick, note, ISO, or unsigned template instead of a signed addendum, and will store payer phones.) the held is: Signed file required only if phones will be stored. Substitutes fail. Cite ONB-FAQ-001; ONB-POL-001; ONB-POL-002; ONB-POL-003.

## Held

Signed file required only if phones will be stored. Substitutes fail.

## Copilot

Cite ONB-POL-003 §2. Do not accept a tick. Do not print phones.
