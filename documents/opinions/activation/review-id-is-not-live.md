iPe (India Pay) is a fictional payments business. This memorandum is for retrieval after onboarding operations have acted. It does not decide the next field, accept a file, or activate a merchant.

---

## Issue

Whether having an identifier such as a review id means activation has occurred.

## Facts

A review identifier exists. The merchant says the id means they are live.

## Rule

ONB-POL-001 §4.4: the identifier is allocated once and does not change. It is not activation. Refused §3.2 applications receive no identifier.

## Application

An id is a file number. Treating it as a live switch would activate every in-review shop. The Copilot shall not change the id on request, shall not invent an id for a refusal, and shall not say live. The issue is: Whether having an identifier such as a review id means activation has occurred. On these facts (A review identifier exists. The merchant says the id means they are live.) the held is: Identifier ≠ live. Identifier unchanged on request. Cite ONB-POL-001 §4; ONB-CIR-001; ONB-POL-005.

## Held

Identifier ≠ live. Identifier unchanged on request.

## Copilot

Cite ONB-POL-001 §4.4. Do not invent or rotate ids. Do not say live.
