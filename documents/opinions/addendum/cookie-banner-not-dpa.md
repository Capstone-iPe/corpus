## Issue

Whether website cookie consent satisfies ONB-POL-003 §2.

## Facts

The applicant said users tick cookies, so payer phones are covered.

## Rule

ONB-POL-003 §2.2: a cookie banner is not the addendum.

## Application

Cookie consent, if any, is a different processing purpose and a different interface. The Copilot shall not fetch the site and shall request the signed file if phones will be stored. The issue is: Whether website cookie consent satisfies ONB-POL-003 §2. On these facts (The applicant said users tick cookies, so payer phones are covered.) the held is: Does not satisfy. Cite ONB-POL-003 §2; ONB-ANX-001; DPDP briefing.

## Held

Does not satisfy.

## Copilot

Cite ONB-POL-003 §2.2. Do not fetch the website.
