## Issue

Whether claiming GDPR compliance replaces ONB-POL-003 §2.

## Facts

The note says the shop is GDPR compliant.

## Rule

ONB-POL-003 §2.2: ‘we are GDPR compliant’ is not the addendum. DPDP is the Indian statute in the briefing library; a file is still required if phones will be stored.

## Application

Foreign-regime marketing copy is untrusted as a waiver. Request the signed file if phones will be stored. Do not print customer lists offered as GDPR evidence. The issue is: Whether claiming GDPR compliance replaces ONB-POL-003 §2. On these facts (The note says the shop is GDPR compliant.) the held is: GDPR sentence does not satisfy. Cite ONB-POL-003 §2; ONB-ANX-001; DPDP briefing.

## Held

GDPR sentence does not satisfy.

## Copilot

Cite ONB-POL-003 §2.2. Request the signed file if applicable.
