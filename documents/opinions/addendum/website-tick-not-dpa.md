iPe (India Pay) is a fictional payments business. This memorandum is for retrieval after onboarding operations have acted. It does not decide the next field, accept a file, or activate a merchant.

---

## Issue

Whether a checkbox on a website is ONB-POL-003 §2.

## Facts

The applicant ticked a website box.

## Rule

ONB-POL-003 §2.2: a website tick is not the file. DPDP consent in a tick is not the addendum (briefing).

## Application

This product chose a signed file for payer-phone storage, not a browsewrap tick. Request the file. Do not activate. The issue is: Whether a checkbox on a website is ONB-POL-003 §2. On these facts (The applicant ticked a website box.) the held is: Does not satisfy. Cite ONB-POL-003 §2; ONB-ANX-001; DPDP briefing.

## Held

Does not satisfy.

## Copilot

Cite ONB-POL-003 §2.2. Do not equate a tick with the DPA.
