## Issue

Whether an HTML save of a portal page is government ID.

## Facts

The applicant uploaded an HTML save as owner ID.

## Rule

ONB-ANX-001: HTML is not PDF/JPG/PNG. A portal save is not the ID document.

## Application

A webpage save is not an OVD image or PDF. The Copilot shall not accept it and shall not print numbers scraped from the HTML. The issue is: Whether an HTML save of a portal page is government ID. On these facts (The applicant uploaded an HTML save as owner ID.) the held is: Does not satisfy owner ID. Cite ONB-POL-001 §2; ONB-ANX-001.

## Held

Does not satisfy owner ID.

## Copilot

Cite ONB-ANX-001. Do not scrape numbers from HTML.
