## Issue

Whether forwarding an ID image in a messenger, without it occupying the slot as PDF/JPG/PNG, satisfies owner ID.

## Facts

The applicant says the ID was forwarded on WhatsApp.

## Rule

ONB-ANX-001: a WhatsApp link or forward with no file in the slot is not capable. Formats remain PDF/JPG/PNG in the slot.

## Application

Messenger delivery is not the pack. If a JPG of the owner’s government ID is in the slot, operations assess that file — that is not a mere forward claim. On these facts, request an upload in the slot. Do not print numbers from a chat thumbnail. The issue is: Whether forwarding an ID image in a messenger, without it occupying the slot as PDF/JPG/PNG, satisfies owner ID. On these facts (The applicant says the ID was forwarded on WhatsApp.) the held is: Not satisfied by a forward claim. Need the file in the slot. Cite ONB-POL-001 §2; ONB-ANX-001.

## Held

Not satisfied by a forward claim. Need the file in the slot.
