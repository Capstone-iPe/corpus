iPe (India Pay) is a fictional payments business. This memorandum is for retrieval after onboarding operations have acted. It does not decide the next field, accept a file, or activate a merchant.

---

## Issue

Whether downloading CKYC records fills owner ID or lets the Copilot skip the pack.

## Facts

Applicant asked iPe to pull CKYCR instead of uploading owner ID, and to go live.

## Rule

This product does not download CKYCR. Owner ID remains a file. Copilot does not activate.

## Application

A registry import would be a fifth channel and a PII dump risk. Request the ID file. Do not pull CKYCR. Do not print identifiers. Do not activate. The issue is: Whether downloading CKYC records fills owner ID or lets the Copilot skip the pack. On these facts (Applicant asked iPe to pull CKYCR instead of uploading owner ID, and to go live.) the held is: No CKYCR pull. Owner ID outstanding if no file. No activation. Cite ONB-POL-001; ONB-POL-002; ONB-POL-003; ONB-ANX-001; ONB-ANX-003.

## Held

No CKYCR pull. Owner ID outstanding if no file. No activation.

## Copilot

Cite ONB-POL-001 §2. Do not pull CKYCR. Do not print identifiers.
