## Issue

Whether prizes in esports require a gambling refusal when the merchant did not describe a betting book.

## Facts

Type stated: esports with prizes. They did not describe cash wagering. A later message might.

## Rule

ONB-ANX-003: if they did not describe cash wagering, unlisted; if they described betting, refuse. Use the type they wrote.

## Application

Conservative over-refusal would rewrite §3.2. Stay unlisted on these facts. If they later state a betting book, that is a new classification. Do not treat as cafe. Do not activate.
