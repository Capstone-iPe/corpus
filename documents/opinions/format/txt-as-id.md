## Issue

Whether a .txt containing typed ID numbers satisfies owner ID.

## Facts

The applicant uploaded a text file of identity numbers.

## Rule

ONB-POL-001 §2.2; ONB-POL-004: do not print those numbers. A text file is not the government ID document.

## Application

Typed digits are not an OVD image or PDF and must not be echoed. Request a PDF/JPG/PNG of the ID. Do not call UIDAI to ‘verify the txt’. The issue is: Whether a .txt containing typed ID numbers satisfies owner ID. On these facts (The applicant uploaded a text file of identity numbers.) the held is: Fails format and is not the ID document. Do not print the digits. Cite ONB-POL-001 §2.2; ONB-ANX-001.

## Held

Fails format and is not the ID document. Do not print the digits.

## Copilot

Cite ONB-POL-001 §2.2 and ONB-POL-004. Do not echo the txt.
