## Issue

Whether a dark store is grocery if so applied, or unlisted fulfilment if so named, and whether it waives shopfront.

## Facts

The merchant named the type as dark store, not grocery.

## Rule

ONB-ANX-003: dark store is unlisted if so named; not grocery unless applied as grocery. Shopfront not waived.

## Application

They named dark store. Unlisted. A windowless fulfilment point still has a front for the photograph if they submit as a shop; the Copilot shall not waive it. If they had written grocery, this memo would not recast them. Do not refuse as money service.

## Held

Unlisted on these facts. Shopfront not waived.

## Copilot

Cite ONB-ANX-003. Do not waive shopfront.
