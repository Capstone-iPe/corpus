## Issue

Whether an unsigned DPA on Tamil Nadu stamp paper is signed because duty was paid.

## Facts

The addendum is stamped in Tamil Nadu and unsigned. Payer phones will be stored.

## Rule

ONB-POL-003 §2.4; stamp briefing: stamp duty does not replace signature.

## Application

State stamp schedules change duty, not this product’s signature requirement. The Copilot shall not accept the unsigned file and shall not activate. The issue is: Whether an unsigned DPA on Tamil Nadu stamp paper is signed because duty was paid. On these facts (The addendum is stamped in Tamil Nadu and unsigned. Payer phones will be stored.) the held is: Unsigned remains outstanding. No state stamp exception. Cite ONB-POL-001 §2; ONB-POL-002 §6; ONB-ANX-001.

## Held

Unsigned remains outstanding. No state stamp exception.

## Copilot

Cite ONB-POL-003 §2. Do not accept unsigned stamped paper.
